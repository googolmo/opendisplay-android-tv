# Project Instructions

This repository contains an Android TV app. See the [README](README.md) for the project overview and the [protocol specification](PROTOCOL.md) for protocol details.

## Writing

- Write documentation and code comments in simple, clear English.
- Keep this file focused on project-wide instructions. Put detailed information in the relevant project documents below.

## Android UI

- Follow Material 3 design and use Jetpack Compose for TV.
- Prefer the available Material 3 components. Do not build a custom control when a suitable Material component exists.
- Keep the interface simple and easy to use with a TV remote.
