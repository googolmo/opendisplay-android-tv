# ストア掲載文 — 日本語（日本）

**アプリ名**

OpenDisplay TV Receiver

**簡単な説明**

Android TVをMacのワイヤレスディスプレイとして使えます。

**詳しい説明**

OpenDisplayを使って、Android TVまたはGoogle TVをMacのワイヤレスディスプレイとして利用できます。

OpenDisplay TV Receiverは、ローカルネットワーク上でmacOS版OpenDisplayアプリからの接続を待ち受け、受信したH.264映像をテレビに表示します。Macの画面をミラーリングしたり、テレビに拡張表示したりできます。

主な機能:
- Bonjour / mDNSを使って、ローカルネットワーク上のレシーバーを検出。
- AndroidのハードウェアアクセラレーションによるH.264デコード。
- 自動、1080p、1440p、4K UHDの解像度モードを選択。
- カーソル表示と、フレームレート、帯域幅、遅延を確認できる再生HUD。
- Android TV向けに設計され、テレビのリモコンで操作可能。

使い方:
1. Android 10以降を搭載したAndroid TVまたはGoogle TVに本アプリをインストールします。
2. テレビとMacを同じローカルネットワークに接続します。
3. 本アプリを開き、MacのOpenDisplayアプリからレシーバーに接続します。

本アプリは受信専用です。Macの画面を配信するには、macOS版OpenDisplay送信アプリが必要です。映像品質は使用する機器とネットワーク環境によって異なります。4Kモードを利用できますが、滑らかに再生できるかどうかは機器のデコーダー性能とネットワーク帯域に左右されます。

OpenDisplayは独立したオープンソースプロジェクトであり、AppleまたはGoogleとは提携していません。
